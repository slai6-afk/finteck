# Finteck Prototype

Interactive Penny prototype in a single HTML file.

## Live mockup (GitHub Pages)

After you enable Pages (see below), the app is served from the project root, for example:

- **https://slai6-afk.github.io/finteck/** → redirects to the prototype page
- **https://slai6-afk.github.io/finteck/Penny%20Prototype.html** — direct link

**One-time setup:** in the repo on GitHub go to **Settings → Pages** → **Build and deployment** → **Source: Deploy from a branch** → choose **main** and folder **/ (root)** → Save. Wait a minute for the first build, then use the links above.

## Run locally

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000/) (or [http://localhost:8000/Penny%20Prototype.html](http://localhost:8000/Penny%20Prototype.html)).
